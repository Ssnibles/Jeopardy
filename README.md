# Jeopardy

## Setup

Clone the repo:

```bash
git clone git@github.com:Ssnibles/Jeopardy.git
```

## To start the server

```bash
cd Jeopardy # or wherever the files are stored
npm start # to run the server
```

> [!IMPORTANT]
> Make sure the terminal with the server stays open or the server will die :(
